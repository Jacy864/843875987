# RP Shell — 手機端純前端 GLM 角色扮演

> 單文件、零依賴、無後端。瀏覽器直連智譜 API，資料全存本機。
> 架構同 RisuAI 路線：前端只是殼，模型與數據主權都在你手裡。

## 快速開始

1. 手機瀏覽器打開 `index.html`（任一方式）：
   - 檔案管理器直接打開（推薦加進瀏覽器書籤/主屏幕）
   - 或局域網：`python3 -m http.server 8080` 後手機訪問 `http://電腦IP:8080`
   - 或扔 GitHub Pages / Cloudflare Pages，永久在線（HTTPS 域名後可「加到主屏幕」當 App 用，離線也打得開——已內建 manifest＋service worker＋圖標）
2. 「設置」填 API Key（bigmodel.cn 後台申請），模型默認 `glm-5.2`
3. 「人設」寫角色卡 → 開聊
4. 模型填 `mock` 可無 Key 試玩全部介面流程

## 用 Coding Plan 訂閱額度（重要）

**普通 API Key 和 Coding Plan 是兩條通道**。報「資源包不足額度」= 你拿 Coding Plan 的 Key 打了普通端點。Coding Plan 有三條專用端點，**推薦第一條**：

| 選項 | 端點 | 瀏覽器直連 | 模型 |
|---|---|---|---|
| **套餐（OpenAI 格式）·推薦** | `https://open.bigmodel.cn/api/coding/paas/v4` | ✅ 已實測放行（含本地文件打開） | **glm-5.2 原生可用**（與 Operit 同路）/ glm-5.3 / flash 系 |
| 套餐（Anthropic 格式）·備選 | `https://open.bigmodel.cn/api/anthropic` | ❌ CORS 預檢不通，需 Cloudflare Worker 反代（見 worker.js） | glm-5.3 / glm-5.3-flash（填 5.2 會被自動升級） |

**設定（推薦路線，零部署）**：
1. 設置 → API 格式 → **GLM Coding Plan 套餐（OpenAI 格式·推薦）**（Base URL 自動切到 coding 端點）
2. 模型填 `glm-5.2`，Key 填 Coding Plan 的 Key → 開聊

額度規則：每 5 小時 + 每週積分上限（Lite 10000/週、Pro 60000/週、Max 140000/週）；夜間 23:00–09:00 及假日有 5 折活動，flash 系模型更省。官方條款：套餐額度「僅限指定編碼工具」，自有前端屬灰色使用，後果自擔（與 Operit 接法同理）。

## 故障排查速查（2026-10-18 確診）

**症狀**：Chatbox／前端突然全部「連接錯誤」，換新建 Key 無效，次日又自己好了。

**結論**：寬帶出口鏈路抖動（非 Key、非服務端、非白名單攔截）。三路徑對比確診——寬帶 ❌ / 國內流量卡 ✅ / 澳門卡 ✅ → 故障鎖定寬帶出口段。**再遇到「連接錯誤」先切流量卡驗證，30 秒定性，別急著動 Key。** workers.dev 對國內寬帶本就不穩（Anthropic 路線的單點），長期可給 Worker 綁自訂域名。

**官方政策變化（2026-10-16 生效，順帶核實）**：

- API Key 分三類互不通用：標準 Key（標準 API 頁）／個人套餐 Key（個人套餐→套餐概覽頁）／團隊套餐 Key；**10-16 前的歷史 Key 無需更換**，密鑰值與規則不變
- 新建 Key 報 `1314 您的企業套餐已失效` = Key 建在了失效的團隊／企業組織下。個人套餐 Key 入口只在「**默認組織的默認項目**」下展示——建 Key 前先看控制台右上角組織切換器
- 端點判定差異：OpenAI 格式端點（coding/paas、paas）按 **Key 歸屬**判額度；Anthropic 端點按**賬號有效套餐**放行（連 1314 Key 實測都能通）
- 「第三方客戶端白名單攔截」未觀測到（Chatbox UA／瀏覽器 UA 實測 coding 端點均 200），官方條款的工具限制目前只體現在計費條款層面

**錯誤碼速查（全部實測）**：

| 響應 | 含義 | 處置 |
|---|---|---|
| `401 令牌已过期` | Key 錯（截斷／已刪） | 核對完整 Key：49 位兩段式 `32位ID.16位密碼`，只複製前半段必 401 |
| `429 1314 企業套餐已失效` | Key 掛在失效團隊套餐 | 切回默認組織重建 |
| `429 1113 余额不足` | 端點與 Key 額度不匹配／套餐額度用盡 | 核對端點，或等 5 小時週期 |
| `429 1302 速率限制` | 賬戶級限流（連續請求觸發） | 稍等自恢復 |
| `429 1305 访问量过大` | 模型容量瞬時限流 | 重試 |
| 連接錯誤／超時 0 字節 | 網絡層（大概率寬帶出口） | 切流量卡驗證 |

**症狀鑑別**：主對話正常但圖片描述失敗（「到側欄檢查視覺模型配置」）＝視覺鏈路走**普通端點**按 Key 判定，而主對話走 Anthropic 端點按賬號套餐放行——兩者可用性不同步。解法：視覺區域 Base URL 留空（自動切普通端點）＋單獨填有效 Key（歷史兼容 Key 實測可调 `glm-4v-flash`）。勿在視覺區域填 coding 端點（只收文字模型）。

**跨境鏈路時通時斷（澳門卡／澳門校園 WiFi，2026-10-18 確診）**：大陸卡境內直連 bigmodel 穩定；澳門卡/跨境 WiFi 到 `open.bigmodel.cn` 走跨境轉接，尖峰時段反覆「Failed to fetch」、過一會又自己好。鏈路品質控制不了，v5.16 起應用層自動重試＋備用線路切換抹平（見「斷線自動重試＋備用線路」節）；徹底解法是掛 Cloudflare Worker 當備用線路。

## 對話消息操作（v5.14）

- **↻ 重roll（Swipe）**：每條 AI 回覆帶 ↻ 鈕，點擊以「到該條為止」的上下文重新生成；新回覆追加為新版本，下方出現 `◀ 2/3 ▶` 切換條可隨時回看/換回任意舊版。只有當前選中版本進上下文，其餘版本不佔 token。生成中可照常點停止
- **改完自動重答**：點「改」編輯 user 消息保存後不再只是存檔——
  - 後面已有 AI 回覆：那條自動重新生成（舊答保留為版本，切換條可回看）
  - 是最後一條消息：直接觸發新回答
  - 改 AI 消息仍為純保存（手動修正文案用）

## 斷線自動重試＋備用線路（v5.16）

- **背景**：手機跨境網絡（澳門卡／跨境校園 WiFi）到 `open.bigmodel.cn` 要走跨境轉接，尖峰時段時通時斷——以前一次 fetch 失敗就直接報「Failed to fetch」，現在應用層自動抹平：
- **自動重試**：網絡層失敗（Failed to fetch／串流中斷）自動重試 2 次（0.9s／1.8s 遞延，每條線路最多 3 次嘗試）；5xx 網關錯也重試；生成中斷線整段重發（氣泡從頭重寫，成本是重新生成）
- **備用線路**：設置→模型設置→「備用線路 Base URL／Key」。主線路 3 次全失敗自動切換過去（Key 留空＝用主 Key）。最穩做法：把 `worker.js` 部署到 Cloudflare Worker（免費、5 分鐘），澳門卡連 workers.dev 不經跨境擁堵段，Worker 出口到 bigmodel 走 Cloudflare 骨幹——備用線路填 `https://你的Worker.workers.dev/api/coding/paas/v4`
- **不重試的情況**：1301 內容攔截（換線路沒用，照舊自動走英文重試）；4xx 業務錯直接顯示（有備用線路時會換線路再試一次）
- `worker.js` 已支援雙路徑：`/v1/messages`（Anthropic 格式主線路）與 `…/chat/completions`（OpenAI 格式備用線路，路徑原樣透傳）

## 環境感知（時間＋天氣＋時間感知）

- 每次發送自動在 system 最前注入 `[環境] 現在時間：2026-10-02（週五）21:35`——模型從此知道今天幾號、聊「今天／昨晚」不會錯亂
- **訊息時間戳＋間隔感知（v5.15）**：模型無狀態，天生看不見「兩則訊息之間隔了多久」——歷史不帶時間座標時，它的印象凍結在所有消息「同時發生」。現在一併解決：
  - 每則訊息發送時帶 `[10-18 14:32] ` 前綴（只發給 API，本地顯示不變）——模型看得見完整時間線，能自行推算任意兩則間隔，隔天回來聊「昨天聊到…」也連貫
  - 與上一則間隔 ≥5 分鐘時，環境行追加「距上一則訊息約 2 小時 5 分」——角色自然知道你離開了一陣子
  - 1301 英文重試版保留時間戳前綴；設置→「訊息時間戳（模型可感知間隔）」可關
  - **回覆防模仿（v5.17）**：模型看到前綴後容易跟著在回覆裡輸出 `【10-18 21:30】` 這類標記——現在系統提示明確告知「那是系統標記，回覆禁止攜帶」，且輸出端強制剝離（串流顯示、存檔、中止路徑全覆蓋，全形【】／半形[]／行中出現都清）
- 天氣：定位（僅城市級精度）→ Open-Meteo 免費 API（無需 Key）→ `所在地天氣：晴 18°C（體感 16°C），濕度 55%` 一併注入；**每日自動刷新一次**，快取存本機
- 隱私：定位坐標只用於查天氣，絕不進對話上下文；本地 file:// 打開拿不到定位時自動跳過天氣（時間照常），HTTPS／PWA 下正常
- 設置→「環境感知」可分別開關日期時間／訊息時間戳／天氣，並顯示目前快取＋手動刷新

## 敏感度控制（四層）

| 層 | 手段 | 位置 |
|---|---|---|
| 端點 | bigmodel 1301 硬攔 → 換 `https://api.z.ai/api/paas/v4`（國際版，社群反饋較寬） | 設置→Base URL |
| 提示詞 | 全域 System Prompt 完全自定義（可放破甲/文風指令，{{char}}{{user}} 自動替換） | 設置→System Prompt |
| 詞表 | **敏感詞軟化**：內建約 60 條成人/粗口/暴力詞（簡繁，源碼 \u 轉義存放）自動替換 + 自訂詞表追加（如 `人名=>通稱`）；發送到 API 時替換、本地顯示保持原文；模型輸出中的軟詞會自動還原回原詞（低誤傷表）再顯示。誤傷機制見 zai-org/feedback#516：平台層輸入/輸出雙檢、無關閉開關 | 設置→敏感詞軟化 |
| 重試 | **1301 自動英文重試**：被攔截時自動把該條 user 消息翻成英文（走視覺模型端點）重發一次，英文輸入觸發率顯著更低；再失敗才顯示錯誤 | 自動 |
| 輸出 | 正則清洗：每行 `規則###替換為`，抹掉說教/口癖/水印 | 設置→清洗正則 |

## 圖片分享日常（純文字模型的視覺外掛）

- 輸入欄 📷 選圖 → 本地壓縮 → 調**視覺模型**（默認 `glm-4v-flash`，走 bigmodel 普通端點——Coding 端點只收文字模型，設置留空自動切換；Key 可與主 Key 相同）生成 80~160 字第一人稱描述 → 以 `[我分享了一張照片：…]` 入對話，氣泡內顯示縮圖
- **氣泡只顯示你的原文＋縮圖**，照片描述僅供模型閱讀（v5.9 起渲染層剝離描述標記；點「改」編輯時也只出現原文，描述自動保留在發送內容裡）
- caption prompt 已限制「不猜地名/事件名、不做政治聯想」，生成後再過一遍軟化詞表，雙保險
- 縮圖（~320px）存 localStorage 隨消息保存；描述失敗會降級為佔位文本不中斷對話

## 記憶系統

- **項目分組**：Sessions 旁的資料夾鈕建「項目」。項目＝獨立的記憶/人設空間：項目內所有對話共享同一份角色人設與長期記憶（隨改隨生效，摘要也寫進去）；項目外開的對話是全新空白記憶。對話的「組」鈕可移入/脫離項目（帶走副本，記憶按分區合併）；刪項目不刪對話
- **結構化記憶（v5.9）**：長期記憶改為手風琴分區——用戶角色 / AI角色形象 / 喜好與偏好 / 關係進度 / 稱呼變化 / 關鍵事件 / 約定與伏筆 / 秘密與暗線 / 場景與世界觀 / 其他備註。每區可直接編輯，改動**即時保存**（不用點保存鈕）；「全開/全收」一鍵展開；注入對話時格式化為 `【分類名】` 段落
- **自動摘要（融合式）**：點「自動摘要對話（融合舊記憶）」，把**當前記憶 JSON＋最近對話**一起發給模型，模型按分類歸類指引（每類寫什麼都有明確說明）輸出融合後的完整 JSON 逐區覆蓋——舊的有效保留、過時的改寫、新的補入（max_tokens 8000，流式生成，bigmodel/z.ai 官方端點自動帶 `thinking:disabled` 防思考耗盡 token）；**按鈕實時顯示進度**（已生成字數·耗時），生成中不可重複點擊；**流式無正文時自動降級非流式重試**，仍空則報告 finish_reason 與思考字數診斷；**JSON 提取容錯**：自動剝離 `<think>` 思考塊／代碼圍欄／解釋文字，輸出被截斷時自動補全引號括號修復 JSON（toast 註明「截斷已修復」）；模型沒按 JSON 輸出時降級併入「其他備註」（think 塊不會混入）可手動搬移。摘要附加指令可清空（清空即只用標準指令）。摘要附加指令（側欄可改）拼在標準指令之後
- **遷移**：舊版純文本記憶自動落入「其他備註」區，不丟失
- **永久**：全部數據存 localStorage，卸載頁面不丟；「側欄→導出備份」生成 JSON（ver4，含項目）可遷移任何設備，舊備份 ver2/ver3 也能導回；恢復方式：備份 JSON 貼進「導入對話記錄」文本框（或選檔案）→ 點「開始導入」自動識別整庫恢復
- **上下文**：點頂欄「模型 · N 條 · 帶M」副標隨手調——檔位「無限 · 20 · 50 · 100 · 200」或滑桿/數字微調（也可在模型設置調，0＝不限帶全部）；太長易觸發攔截，長劇情靠摘要補
- **輸出上限**：預設不設限（請求不帶 max_tokens，走模型上限）；要限就點檔位「2k/4k/8k/16k」或填數字
